# Hats

One router page per role you work in. The entry point when you step into that context.

A hat page holds the things that are true for that role and nowhere else: who the key people are, what the standing arrangements are, which cases are live, who decides what, and the conventions specific to working there.

It does not duplicate the case pages. It links to them.

## Template

```markdown
---
title: <Hat name>, router
name: <Hat name>
type: reference
status: active
confidence: verified
hat: <hat-slug>
created: YYYY-MM-DD
updated: YYYY-MM-DD
tags: [hat, router]
---

TL;DR. One line on what this role is and what it is responsible for.

```
